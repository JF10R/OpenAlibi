# Asset sources

OpenAlibi currently ships no third-party runtime artwork, font files, audio, or icon packages.

| Asset group | Location | Source | License record |
|---|---|---|---|
| Furniture and evidence drawings | `src/app.js` (`OBJECT_SVGS`) | Original inline SVG drawn for OpenAlibi | Repository license |
| Room colors and surfaces | `src/core.js`, `styles.css` | Procedurally selected colors and original CSS patterns | Repository license |
| Character avatars | `src/app.js`, `styles.css` | Programmatic initials, hues, and CSS shapes | Repository license |
| Brand and interface styling | `index.html`, `styles.css` | Original OpenAlibi markup and CSS | Repository license |
| Gameplay screenshot | `docs/images/openalibi-gameplay.png` | Captured from OpenAlibi | Repository license |

## Adding assets

For every added image, icon, font, sound, dataset, or generated artifact, record:

- exact file or source-code location;
- author or originating tool;
- creation or acquisition date;
- source URL when applicable;
- license and required attribution;
- modifications made;
- confirmation that the asset does not reproduce a commercial puzzle or another product's protected visual expression.

Prefer original editable vector or procedural sources. Do not use another mystery puzzle game as an art reference.
